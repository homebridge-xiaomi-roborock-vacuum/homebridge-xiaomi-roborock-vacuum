Vacuums in the old format

These vacuums are configured as accessories, the format of versions before 1.0. They work, but this page and the form below can't show or change them.

    Moving them to the new format (platform) keeps all their options. The Home app sees them as new accessories: you'll have to put them back in their rooms, and update your scenes and automations. A backup of your config is saved first (Settings → Backup).

    Xiaomi Cloud (optional)

    Log in to get your vacuums' tokens, see their map to name the rooms, and (with the "Xiaomi Cloud" option below) know which room they're cleaning. Your password is never needed: scan a QR code with the Mi Home app.

    Rooms, spots and zones from the map (Roborock)
    Click a room (or use the list) to name it: the names become the room cleaning switches. Tick 2x / 3x to also get "Kitchen 2x" switches, which clean the room 2 or 3 times (you can rename them in the Home app).
    • The robot takes one count for the whole run: if you turn on rooms with different counts together, the highest applies to all of them.
    • Roborock robots clean a room at most 3 times in a row.
    • Some older firmwares don't support repeating: the switch then logs an error.
    Click on the map to add a spot, and name it. Each spot becomes a "go to …" switch: on sends the robot there, off sends it back to the dock.
    • Pick spots the robot can reach: it stops if the way is blocked.
    • The coordinates belong to this map: if the robot's map is reset or created again, pick the spots again.
    Drag on the map to draw a zone, and name it. Each zone becomes a switch that cleans that area, 1 to 3 times.
    • Zones that come from your config with several rectangles keep all of them.
    • The coordinates belong to this map: if the robot's map is reset or created again, draw the zones again.

    This is the last map the robot saved in the Xiaomi Cloud.
